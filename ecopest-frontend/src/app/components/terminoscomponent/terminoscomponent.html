Términos y condiciones de uso

Última actualización: 25 de noviembre de 2026

1. Propósito de EcoPest

EcoPest es una aplicación web desarrollada como proyecto del curso Arquitectura de Aplicaciones Web de la UPC. Permite registrar empresas, inspecciones, incidentes de plagas, evidencias, recomendaciones y datos de clima.

2. Uso de la cuenta

Cada persona usa su propio correo y contraseña. Las opciones que se muestran dependen del rol asignado (administrador, supervisor, tester o cliente). No se deben compartir las credenciales.

3. Recomendaciones generadas con IA

Las recomendaciones marcadas con el ícono de IA son sugerencias de un modelo de lenguaje. Deben ser revisadas por una persona responsable antes de aplicar cualquier producto o método de control.

4. Servicios de terceros

EcoPest consulta servicios externos: Open-Meteo y MET Norway para el clima, iNaturalist para el catálogo de especies, Nominatim para ubicar una zona y Gemini para la IA. Estos servicios pueden fallar o cambiar sus límites de uso; cuando ocurre, la aplicación muestra un aviso y no guarda datos incompletos.

5. Datos personales

La aplicación guarda el nombre, el correo y el rol de cada usuario únicamente para identificar quién registra la información. Las contraseñas se almacenan cifradas y los datos de demostración no corresponden a empresas reales.

6. Alcance académico

El sistema se entrega con fines educativos. No sustituye la evaluación de un profesional en control de plagas.
