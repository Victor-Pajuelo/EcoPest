# EcoPest

Sistema de gestion preventiva de plagas desarrollado con Spring Boot y SQL Server.

## Estructura

- `ecopest/` codigo fuente de la aplicacion principal
- `sql/` scripts SQL de base de datos
- `sql/bd_ecopest_v3.sql` script principal de la base de datos

## Base de datos

Ejecuta primero `sql/bd_ecopest_v3.sql` para crear la base `EcoPestDB` y sus tablas principales.

## Aplicacion

Abre el proyecto `ecopest/` desde tu IDE y ejecuta la clase principal `EcoPestApplication`.
